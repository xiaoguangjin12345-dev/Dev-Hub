# Dev Pulse : 软件研发团队项目管理与绩效量化平台


## 1. 项目简介
本项目是针对软件研发团队的项目管理系统，围绕PMO、项目经理、开发人员、系统管理员这四个角色设计，集成项目创建与审批、任务分配与匹配、工时填报与审计、绩效量化与评价等核心功能模块，以及消息通知、数据统计等辅助功能模块。
#### 1.1 业务特点
- **业务流程闭环**：实现项目的立项申请、审批、进行中、申请结项、存档，以及任务的分配、匹配开发人员、进行中、评审、完成等核心业务的全流程闭环。
- **任务双向匹配机制**：项目经理分配任务后，可邀请开发人员；开发人员也可申请待分配任务；只有双向选择匹配后，该任务才锁定指定开发人员。
- **绩效分级与量化**：两级绩效评价机制，分别针对项目经理与开发人员；各级绩效数据只有30%来自上级主观评定，其余70%全部源自工时、评审等系统记录的数据。
- **智能辅助决策试点应用**：针对指定项目，根据ID获取项目名称、项目描述等信息，拼接至预设Prompt模板，并设计tools约束指定JSON格式，以请求网络大模型API的形式完成任务分配建议；生成的结果经反序列化并进行格式与内容校验后，返回至前端渲染任务分配建议的表格，以辅助项目经理执行任务分配的决策。

#### 1.2 技术特点
- **Redis缓存应用**：针对选项框、项目或任务详情、用户姓名等热点数据，优先读取Redis缓存，未命中时查库并写入，通过差异化TTL（并根据角色或用户ID区分Key）及随机波动防止大量缓存同时失效，减少数据库I/O。异步场景中，利用Redis暂存请求状态并返回Key供前端轮询，业务处理完成后根据结果写入状态并设置TTL（失败态一般60秒以内），实现高效的状态同步。

- **Redisson分布式锁应用**：在任务双向匹配及PMO审批等关键操作中，使用分布式锁约束临界区，防止并发导致数据覆盖或匹配错乱，配合二次校验保证一致性。单体架构下也可用Java原生锁或乐观锁替代。

- **RabbitMQ应用**：通过RabbitMQ实现工时填报削峰、统计报表及AI服务限流，配置有限监听器并限制单次处理一条消息，配合Redis轮询状态，实现异步解耦与线程池保护，为后续AI服务扩展预留能力。

- **数据库实现**：MySQL采用InnoDB与utf8mb4，支持事务、行级锁与完整Unicode；MyBatis动态SQL实现权限控制与数据隔离；`@Transactional`保证多表操作原子性，异步消息通知在事务提交后发送。
